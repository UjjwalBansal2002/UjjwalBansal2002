## 👨‍💻 About Me

I am a **Native Android Developer** specializing in building reliable, scalable, and responsive Android applications using **Kotlin**, **Jetpack Compose**, and modern **Android Jetpack components**.

With hands-on experience across the entire mobile application lifecycle, I focus on turning complex product specifications into smooth, production-ready user experiences. My development approach emphasizes **clean architecture (MVVM + Repository pattern)**, lifecycle-safe data handling, robust API networking, and secure local/remote data synchronization.

- 🛠️ **Core Strengths**: Native Android (Kotlin/Java), Jetpack Compose, XML UI, MVVM, Retrofit & OkHttp, Hilt, Firebase, Room/DataStore.
- ⚡ **Domain Experience**: Real-time consultation & astrology platforms, recruitment/job listing systems, multi-role vendor ecosystems, and location-driven utility applications.
- 🔐 **Security & System Capabilities**: Secure AES encryption/decryption on API payloads, OTP & SMS Retriever integration, token auth management, Firebase Analytics & Crashlytics, FCM push notification routing, and Google Maps integration.
